# 对局界面：竖屏 / 横屏的交互区设计

参考图给的是"上面打牌、下面一张信息页"的手游结构。这套界面按同样的信息层级重做了一遍，
但**比例不硬性锁 1/3**：一切以画面完整、操作顺手为准，交互区该多高就多高，可以拖、可以收。

## 一、信息分层

| 层级 | 放在哪 | 内容 |
|---|---|---|
| 常驻功能 | 顶部工具条（永远在） | 大厅（返回）、房号/玩法名、邀请、规则、战绩、托管、牌面、播报 |
| 关键信息 | 交互区标题行 + 牌桌内自带信息条 | 轮到谁、思考倒计时、阶段（叫分/换牌/出牌中/本局结束） |
| 次要信息 | 交互区两张卡 | 左：牌友状态（头像、谁托管/思考中/掉线、剩几张牌或积分）；右：本房娱乐分（进房以来累计，或单人局的座位分） |
| 交互 | 交互区主体 | 牌桌聊天：消息、快捷语、表情、输入框 |

## 二、竖屏

- 牌桌在上，信息页在下，信息页默认约 **220–300px**（约内容区 1/3，按屏幕大小自适应）。
- 信息页上沿压住牌桌 14px：手牌底部自然"藏"进纸面，像真的铺在桌沿上。
- 三档高度，都能拖出来：
  - **展开**：信息页 + 聊天全露；
  - **收起**：只留标题行（约 56px），牌桌立刻变大；
  - **隐藏**：整块收起，右侧边缘留一个圆形按钮随时唤回。
- 拖动开关：信息页顶部那条短横线，上下拖跟手，松手按距离和甩动速度吸附到最近一档（带轻微回弹）。

## 三、横屏

- 信息页整高贴在右侧，宽约 1/3；牌桌占左侧。
- 同样三档：展开 / 收起 / 隐藏，只是拖拽方向变成左右。
- 牌桌按"宽度定尺度、用剩余高度当画布"换算，缩放后正好铺满左侧，不留上下黑边。

## 四、牌桌怎么适配（关键）

12 个玩法的界面都是按"满屏"设计的，直接塞进较小的区域会出现座位重叠、按钮被挤出画面。
所以牌桌不重排，而是**整体等比缩放**：

- 竖屏：给画面区一个舒适画布高度（640），只缩到刚好放得下，系数通常在 0.8–0.9；
- 横屏：按宽度定系数（约 0.66），画布高度按比例拉到剩余高度；
- 交互区收起时缩放系数回到 1，等于原来的满屏布局，所以任何时候都不会裁掉操作区。

代价是牌面上的字会按比例变小，所以**关键信息全部在交互区里再给一份**（轮到谁、倒计时、局数、倍数），
不必眯着眼看牌桌上的小字。

## 五、收起到只剩一条时怎么提醒

交互区收起来（或宿主把它收走）以后，牌桌顶部会留一条 28px 的窄带，灯亮着写「轮到 清风（你）· 27 张」。
这条窄带是从牌桌画布里**单独切出来的**，不压座位、不压手牌，也不压游戏自己的信息条 ——
代价只是收起态牌桌少 28px，换来任何时候都不会漏看轮到谁。

横屏的收起条同时改成 96px 宽，只留「牌桌信息 / 表情 / 展开」，不再把整句话竖着挤在 50px 里。

## 六、横屏开关

顶栏最右多了一个按钮：

- 手机上装的是 APK：点一下走 Android 的 `setRequestedOrientation`，**手机锁着竖屏也会强制逆时针横屏**；
- 浏览器 / H5：走 CSS 旋转兜底（整页 `rotate(-90deg)`，布局尺寸换成 100vh×100vw），效果一样；
- 再点一下回到竖屏或「跟随系统」。

## 七、宿主（模拟器 / 外壳）接管

对局页可以把「工具条 + 交互区」交出去，只留牌桌本体：

- `?host=1`（或 `#host=1`）→ 默认两块都收走，牌桌满屏；
- 宿主用 `postMessage({park:'host', type:'chrome', tools, dock})` 随时开关；
- 页内也可直接 `window.ParkHostAPI.setChrome(tools, dock)`。

详见 `docs/HOST.md`，配套 demo 是 `宿主示例.html`。

## 八、已经踩过并解决的坑

1. 竖屏直接重排 → 麻将上家头像压在顶部信息条上、德州左右座位被切半 → 改成等比缩放。
2. 旧的"矮屏把信息条抬进顶栏"规则（`max-height: 500px`）在真实顶栏下会把信息条藏起来 → 已作废。
3. 麻将的信息条原本是绝对定位浮在上家头像上 → 改成占位一行。
4. 交互区高度原先由内容撑开、不受 1/3 控制 → 改为外层按像素驱动，拖拽才跟手。
5. 结算卡原本固定定位在右上角，横屏会被交互区盖住 → 改为浮在牌桌画面正中。
6. 横屏顶部一条空白：Capacitor 把系统栏安全区当成 WebView 边距加了进来 → 壳里改成整屏铺满，
   安全区只由网页的 `env(safe-area-inset-*)` 处理；牌桌期间页面底色也切成绒布色，缝隙不再露白。
7. 收起态提示直接浮在牌桌上会压住「第 1 局 / 本局打 2」那排信息 → 改成顶部切一条专属窄带。

## 顺时针横屏（turn 档位）

顶栏的「旋转」按钮只做一件事：`turns += 1`（0→1→2→3→0），每按一次画面顺时针转 90°。

- `.table.is-turn-1/2/3` 分别用 `rotate(90deg) translateY(-100%)`、`rotate(180deg) translate(-100%,-100%)`、`rotate(270deg) translateX(-100%)`，同时把 `100vh/100vw` 互换，所以逻辑尺寸与视觉尺寸始终对齐。
- 是否横屏由 `landscape = turns % 2 === 1 ? vp.h > vp.w : vp.w > vp.h` 决定：竖屏下按一次就是横屏，横屏下再按一次回到竖屏并倒转 180°（连续顺时针，不会来回跳）。
- 宿主（模拟器/外层 App）用 `ParkHostAPI.setOrientation('landscape')` 时等价于直接跳到 turn-1，不再有原生锁屏那一套。
- 安全区只由网页的 `env(safe-area-inset-*)` 处理，Android 侧不再预留系统栏边距，横屏不会出现纸白空带。

## 游戏库（`#/library`）

外部游戏统一收在「游戏库」：顶部返回 + 导入，四段筛选（全部 / H5·Cocos / 掌机 / 其它），虚线导入区，卡片列表（平台徽标 + 名称 + 体积 + 打开），详情 Sheet 里改名、删除、复制文件名。

- 文件存在 IndexedDB（`park-library` 库，`roms` 元数据 + `blobs` 文件本体），不占服务器空间、不上传。
- H5 / Cocos 直接开新窗口跑（CSP 已放开 `blob:` 的 script/frame）；FC / GB / GBA 交给外部模拟器，闲亭负责归档、改名与一键找文件。
- 大厅与游戏库共用同一套令牌与组件（`--surface/--ink/--line/--radius`），视觉上是同一个产品。

## 个人中心（`#/me`）

一页式：资料卡（形象、昵称）、外观与主题、联机与局域网、数据、关于。

- 主题三档：自动 / 浅色 / 深色。自动档跟随系统 `prefers-color-scheme`，系统入夜时整个界面（含牌桌以外的所有页面）切到深色，不需要手动切换。
- 桌布、四色牌、记牌器、音效、虚拟形象沿用设置里的同一份 store，改一处全局生效。

## 版本框与退出路径

- 大厅右下角不再放源码链接与「源码」标签，只留一枚版本胶囊：`闲亭 v0.3.0 · 2026.11`。版本号唯一来源是 `apps/web/src/lib/version.ts`，个人中心「关于」用同一个值。
- 管理页（个人中心、游戏库）顶部的返回胶囊改成 sticky：滚动、横屏都不离手；个人中心底部另有一枚常驻「回大厅」，任何朝向下都点得到。

## 交互区的主题适配

交互区（`hud`）不再直接拿 `--surface` 当底色，而是独立一组令牌 `--hud-a / --hud-b / --hud-edge / --hud-shadow`：

- 浅色：暖纸面 `#fffdf8 → #f5f1e8`，上沿一条高光边，阴影偏绒布绿，像压在桌沿的牌谱；
- 深色：`#1b1e1c → #161918` 的暖黑（带一点绒布绿），不是冷灰，和牌桌同一套；
- 三档主题（自动/浅色/深色）都会立刻作用到交互区，不需要重启。

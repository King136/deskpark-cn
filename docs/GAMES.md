# 棋牌玩法与视听迭代路线（业界对标）

目标：把每个玩法的「上手 10 秒 / 一局节奏 / 结算反馈」做到主流商业棋牌的手感，而不是只换皮。
下面按「通用层 → 单玩法层」拆，通用层一改全玩法受益，单玩法层逐款验收。

## 通用层（所有玩法共用）

| 环节 | 现状 | 目标 | 对标 |
| --- | --- | --- | --- |
| 出牌节奏 | 点即出，无预判 | 选牌后 300ms 可撤销窗口 + 出牌飞行 220ms | 欢乐斗地主 / JJ 斗地主 |
| 牌面反馈 | 静态 | 选中抬升 6px + 投影，不可出牌时轻微抖动 | 腾讯欢乐系列 |
| 轮到谁 | 头像描边 | 头像呼吸环 + 顶部窄条（已做）+ 轻微音效 | 雀魂 / 欢乐麻将 |
| 动作条 | 并列三键 | 主操作（出牌/胡）实心金，次操作描边，危险操作灰 | 雀魂 |
| 结算 | 一张卡 | 名次奖牌 + 分数滚动 + 一句人话点评 + 再来一局 | 欢乐斗地主结算页 |
| 音效 | 少量 | 出牌/压牌/倒计时/胜负四类，可全局静音 | 通用 |

## 单玩法层（按优先级）

1. **斗地主**：叫分动画、炸弹全屏震屏、春天/反春文案、记牌器悬浮球（已有开关）。
2. **掼蛋**：级牌提示、进贡/还贡流程可视化、2v2 队友标记。
3. **麻将（四川/国标）**：摸牌高亮、听牌提示、番型结算明细、牌墙进度。
4. **象棋/围棋/五子棋**：落子音、悔棋确认、AI 思考中的"呼吸"占位、胜负手高亮。
5. **UNO / 其他卡牌**：颜色选择器动效、+4 叠加提示、剩余牌数警示。

## 落地顺序

先做通用层（4 项：可撤销出牌、牌面反馈、主次动作条、结算页），再逐玩法补专属规则演出；
每完成一款，用 `tools/screenshot.mjs` 出竖屏/横屏/结算三张图，进 `界面截图/` 做回归基线。
